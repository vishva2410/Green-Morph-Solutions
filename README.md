# Green Morph Solutions 🌿♻️

> **Transforming Plastic Waste into Beautiful Creations**

Green Morph Solutions is a sustainable initiative dedicated to reducing plastic waste by transforming it into stunning, functional furniture. We connect with the community to collect plastic waste, process it, and create high-quality epoxy tables and other products. Join us in making a positive impact on the environment!


---

## 🌟 Features

*   **♻️ Plastic Collection Service**: Schedule a pickup for your plastic waste and get paid $18 per kg!
*   **🛒 Sustainable Marketplace**: Browse and purchase unique epoxy tables made from recycled materials.
*   **📊 Impact Tracking**: View real-time statistics on recycled plastic, trees saved, and CO₂ emissions avoided.
*   **🚚 Live Tracking**: Track your collection pickup status in real-time (integrated with Google Maps).
*   **📱 Responsive Design**: A seamless experience across desktop and mobile devices.
*   **❓ FAQ Section**: Answers to common questions about plastic types and our process.

## 🛠️ Tech Stack

This project is built using the following technologies:

*   **HTML5**: Semantic markup for the structure.
*   **CSS3**: Styling with animations, responsive design, and FontAwesome icons.
*   **JavaScript (ES6+)**: Interactive logic for animations, modal handling, and data processing.
*   **Vite**: Next Generation Frontend Tooling for fast development and building.

## 🚀 Getting Started

Follow these steps to get a local copy up and running.

### Prerequisites

*   **Node.js**: Make sure you have Node.js installed on your machine. You can download it [here](https://nodejs.org/).

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/green-morph-solutions.git
    cd green-morph-solutions
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Start the development server**:
    ```bash
    npm run dev
    ```

4.  **Open in your browser**:
    Visit `http://localhost:5173` (or the port shown in your terminal).

## 📖 Usage

1.  **Home**: Explore the hero section and learn about our mission.
2.  **Schedule Pickup**: Click on "Schedule a Pickup" to open the booking form. Fill in your details and preferred time.
3.  **Shop Products**: Scroll to the "Products" section to view our featured epoxy tables. Use the carousel to see more.
4.  **Track Pickup**: Go to the "Track Pickup" section, enter your tracking ID, and see the status of your collection agent.
5.  **View Impact**: Check out the "Our Impact" section to see the environmental statistics animate.
